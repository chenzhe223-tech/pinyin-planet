# 拼音星球 · Pinyin Planet

给小学一、二年级孩子用的轻量拼音练习小游戏。

- 打开方式：直接双击 `index.html`，或在浏览器里打开这个网址即可，不需要安装任何东西。
- 四个练习模块：b/d 辨认、p/q 辨认、n/l 声母辨认、前后鼻音（an-ang / en-eng / in-ing）。
- 每关 6 题，约 2–3 分钟；答对得一颗拼豆，攒够可以点亮一幅拼豆作品。
- 练习记录只保存在你自己的浏览器里，不上传、不注册、不追踪。

## 在线试玩

GitHub Pages 会自动托管：打开 `index.html` 或访问仓库主页的 Pages 链接。

## 说明

- 语音朗读使用浏览器自带的语音合成，不同设备的声音会略有差别，仅作为辅助提示，不作为唯一判断依据。
- 单文件、零依赖，可以随意复制分享。
